# 秒记账 v6.18.13 - 无感衔接启动页版

## v6.18.13 更新

1. 系统启动页和原生品牌页共用同一个 `splash_logo.xml`，图标尺寸、中心位置和背景色保持一致。
2. 原生层接管后仅补充应用名称、副标题和底部署名，避免视觉上出现两个不同页面。
3. 禁止启动主题强制深色处理，修复部分厂商系统把白色 ¥ 和浅色底板变黑的问题。
4. 缩小系统启动图标的可见区域，接近常见大厂应用启动图标比例。
5. 启动期间状态栏和导航栏保持橘色，进入主界面后再统一恢复暖白色。
6. 软件内部版本、Android 构建版本和发布文件名统一为 v6.18.13。

## v6.18.10 更新

1. 将 `startSplashTransition()` 提前到启动页 DOM 后立即注册，不再依赖后续业务脚本执行成功。
2. 原生端释放系统 Splash 不再等待 JavaScript 回调，避免个别 WebView 回调不触发造成卡死。
3. HTML 启动页增加 2.5 秒自动开始和 4 秒强制关闭双重兜底。
4. 原生系统 Splash 同步保留 4 秒强制释放，任何单点异常都不会让启动页永久停留。
5. 保留 v6.18.9 的橙色 LOGO、交叉淡入、默认字体缩放和其他兼容性修复。
6. 软件内部版本、Android 构建版本和发布文件名统一为 v6.18.10。

## v6.18.9 更新

1. 接入 AndroidX SplashScreen，让系统启动页持续显示到 WebView 完成加载。
2. 系统启动页使用橙色背景与专用圆角人民币 LOGO，避免白屏、空白橙色闪烁和图标跳动。
3. 系统页退出时执行 180ms 淡出，HTML 渐变启动页的标题与副标题同步淡入。
4. HTML 启动页展示完成后再平滑进入首页，并增加 5 秒安全释放机制避免异常页面导致启动页常驻。
5. 保留 WebView 默认文字缩放、Android 15 系统栏、Adaptive Icon 和 Gitee APK 直链。
6. 软件内部版本、Android 构建版本和发布文件名统一为 v6.18.9。

## v6.18.8 更新

1. Android 12 及以上系统启动窗口改为橙色无图标过渡，消除白底大图标启动页。
2. 保留原有橙色渐变 HTML 启动页，并为 LOGO、标题和副标题加入轻微淡入效果。
3. Android 6 至 11 继续直接使用原有 HTML 启动页，Android 12 至 15 与系统启动窗口无缝衔接。
4. 删除 `setTextZoom(100)` 和 `text-size-adjust:100%`，恢复 WebView 原有文字缩放策略。
5. 分享二维码改为 v6.18.8 的 Gitee APK 直链，不再经过 CloudBase 测试域名提示页。
6. 软件内部版本、Android 构建版本和发布文件名统一为 v6.18.8。

## v6.18.7 更新

1. Adaptive Icon 前景人民币符号缩小至 70%，避免部分桌面启动器显示过大。
2. 同步调整旧 Android 系统使用的普通与圆形回退图标。
3. 保留 v6.18.6 的 Android 15 系统栏适配和 WebView 文字缩放设置。
4. 软件内部版本、Android 构建版本和发布文件名统一为 v6.18.7。

## v6.18.6 更新

1. Android 15 暂时退出强制边到边显示，恢复与 Android 13 接近的状态栏和导航栏布局。
2. 固定 WebView 文字缩放并关闭页面自动文字调整，减少不同手机上的 UI 比例差异。
3. 桌面图标改为标准 Adaptive Icon，修复部分桌面启动器四周出现白边的问题。
4. 软件内部版本、Android 构建版本和发布文件名统一为 v6.18.6。

## v6.18.5 更新

1. 启动页标识改为橙色底白色人民币符号，与桌面图标保持一致。
2. 首页左上角标识同步改为人民币符号。
3. 快捷记账通知恢复带图标、分隔线和“记一笔”按钮的紧凑布局。
4. 移除重复的展开通知模板，避免部分系统重复显示通知时间。
5. 检查更新和分享应用在手机、平板上均使用底部整宽面板。
6. 分享海报改为 Canvas 实时生成的账单小票样式。
7. 软件内部版本、Android 构建版本和发布文件名统一为 v6.18.5。

## v6.18.3 更新

1. 年账单自动显示全部历史年份，并按最近年份优先排列。
2. 月、周、日账单按日期由近到远；点击年份可进入该年份的月账单。
3. 登录前后账号卡片改为紧凑单行入口，删除重复提示和大按钮。
4. “账号设置”更名为“个人中心”。
5. 云端返回 `SESSION_KICKED` 或 `SESSION_INVALID` 时显示异地登录提示并退出旧会话，本地账单保留。
6. 图表、快捷通知、通用弹窗及其他功能保持 v6.18.2 原样。

## v6.18.2 更新

1. 更新配置不再强制要求 `apkSize` 和 `sha256`，只需版本号、APK 下载地址和更新说明。
2. 未配置 SHA-256 时仍会校验下载文件的 Android 应用包名；配置 SHA-256 时继续执行完整性校验。
3. 桌面图标调整为不透明橙色底和白色人民币符号。
4. 个人页账号卡片移除邮箱下方的“已登录”提示。

## v6.18.1 更新

1. 检查更新地址固定为 `zhangfsen/mjy-update` 仓库中的 `update.json`。
2. 软件内部版本、Android 构建版本和发布文件名统一为 v6.18.1。
3. Release APK 固定输出为 `MiaoJiZhang-v6.18.1.apk`。

## v6.18.0 更新

1. 云端恢复数量改为统计实际下载的 `entries` 数组，不再优先采用可能过期的 `entry_count`。
2. 服务器统计与实际数组不一致时，在恢复弹窗中显示诊断信息。
3. 恢复与合并始终处理实际下载到的全部云端记录。
4. 登录后的账号卡片去掉重复的“立即同步”，只保留全宽“账号设置”。

## v6.17.0 更新

1. 账号设置新增“从云端恢复”，后续可随时重新读取云端数据。
2. 云端恢复只读取云端，不会在恢复前上传或覆盖云端数据。
3. 支持“合并到本机”和“使用云端替换本机”两种恢复方式。
4. 替换或合并前自动保存本机快照，并支持撤销上次云端恢复。

## v6.16.0 更新

1. 保留登录、注册、账号设置、手动同步和自动同步能力。
2. 精简账号卡片，删除未登录及登录后的云同步说明文字。
3. 删除主题皮肤入口，界面、桌面图标、通知图标及悬浮球固定为默认橙色。
4. 删除非橙色主题样式、动态图标切换接口和未使用的主题图标资源。
5. 删除意见反馈入口及原生本地反馈保存接口。

## v6.15.0 更新

1. 新增启动自动检查更新和设置页手动检查更新。
2. 支持 App 内下载 APK，并实时显示下载进度和文件大小。
3. 下载完成后自动执行 SHA-256 与应用包名校验。
4. 校验通过后自动打开 Android 系统安装程序。
5. Android 8 及以上支持引导开启“安装未知应用”权限并返回后继续安装。

更新配置固定读取 `https://gitee.com/zhangfsen/mjy-update/raw/master/update.json`，参考根目录 `update.example.json` 发布下一版本。

本包在 v6.13.0 基础上将悬浮球与快捷通知拆分控制，并让通知视觉跟随主题皮肤。

## v6.14.0 更新

1. “记账悬浮球”和“快捷记账通知”拆分为两个独立设置。
2. 关闭悬浮球时只移除悬浮球；快捷通知开启时通知继续保留。
3. 关闭快捷通知时，悬浮球若仍开启则继续正常运行。
4. 两项均关闭时才停止前台服务并移除通知。
5. 快捷通知独立运行时标题改为“快捷记账通知”，避免显示“悬浮窗运行中”。
6. 通知图标及“＋ 记一笔”按钮颜色随橙色、绿色、蓝色、紫色、樱花、拿铁、深色和极简主题刷新。

## v6.13.0 更新

1. 首页月度汇总卡进一步缩短，减少上下内边距与装饰占用。
2. 主金额与三项月度数据保持清晰，账单列表整体上移。
3. 悬浮窗前台通知改为自定义紧凑布局，右侧常驻显示“＋ 记一笔”。
4. 点击通知左侧内容打开 App 首页；点击右侧按钮直接进入新增账单。
5. 移除依赖展开状态的系统 Action，避免部分手机折叠时看不到快捷入口。

## v6.12.1 更新

1. 日期标题改为小号次要信息，格式为“8月20日 · 周四”，不再显示“今天 / 昨天”。
2. 首页账单行不再重复显示日期和具体时间。
3. 分类与备注调整到同一行，备注使用更小、更浅的字号。
4. 账单详情继续保留完整日期和具体时间。
5. 缩小日期标题和账单行的垂直间距，一屏可显示更多内容。

## v6.12.0 更新

1. 首页账单明细改为按日期分组，日期显示在左侧，当日支出总额显示在右侧。
2. 日期标题支持“今天 / 昨天 / 星期”提示，同一天的账单集中显示在标题下方。
3. 悬浮窗前台通知新增唯一快捷操作“＋ 记一笔”。
4. 点击通知快捷操作可直接打开新增支出账单面板；App 已运行和未运行两种状态均支持。
5. 保留原有账单点击、长按、编辑、删除、月份切换、悬浮球与云同步逻辑。

## v6.11.1 更新

1. 恢复支出分类“其他”，并作为固定兜底分类显示在“⚙️ 设置”之前。
2. 支出“其他”不参与用户分类拖动排序、编辑和删除；分类管理页会以“固定分类”标识显示。
3. 新建记账时不再默认选中第一个分类：默认只处于“支出”类型，具体分类为空。
4. 切换“支出 / 收入”时会清除当前具体分类，必须由用户主动点击分类后才进入金额输入页。
5. 编辑已有账单时仍保留原来的收支类型、分类和金额，直接进入金额编辑页，不增加额外步骤。

7. 保留 v6.11.0 的固定分类弹层高度、自定义分类新增/编辑/删除/拖动排序、两段式记账、日期、备注、自定义数字键盘、防幽灵点击、悬浮窗和云同步逻辑。
